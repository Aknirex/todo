# 03 — 首页 + 详情页

**What to build:** 用户可完整操作 todo 的 UI — 首页展示 todo 列表（按优先级/时间排序）、快速创建输入框、完成状态切换（左滑/点击）、滑动删除、点击进入详情编辑页（标题/优先级/截止日期/标签/详情）。全局撤销按钮常驻。

**Blocked by:** 02 — 状态管理层

**Status:** ready-for-agent

- [ ] 首页展示未完成 todo 列表，按创建时间倒序
- [ ] 快速创建：输入标题 → 回车 → 创建 todo
- [ ] 完成切换：点击 checkbox 切换完成状态
- [ ] 滑动删除：左滑显示删除按钮
- [ ] 点击 todo 进入详情编辑页
- [ ] 详情页可编辑：标题、优先级、截止日期、标签、详情
- [ ] 详情页保存后返回首页，列表自动刷新
- [ ] 撤销按钮：点击撤销最近一步操作
- [ ] 空状态展示引导文案
- [ ] 页面样式美观，符合极简设计
