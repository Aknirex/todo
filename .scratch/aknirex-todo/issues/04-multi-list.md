# 04 — 多列表管理

**What to build:** 用户可创建多个 todo 列表（按项目/场景分组），首页支持 Tab 切换不同列表，每个列表独立管理 todo。默认列表不可删除。

**Blocked by:** 02 — 状态管理层

**Status:** ready-for-agent

- [ ] 首页顶部显示列表 Tab（默认列表 + 用户创建的列表）
- [ ] 切换 Tab 过滤显示对应列表的 todo
- [ ] 新建列表：输入名称 → 创建
- [ ] 编辑列表：长按重命名
- [ ] 删除列表：删除列表及其下所有 todo（默认列表不可删除）
- [ ] 新建 todo 时自动归属当前选中列表
- [ ] 列表排序支持拖拽调整
