# 06 — 全局搜索 + 筛选

**What to build:** 用户可跨列表搜索 todo（关键词匹配 title/detail/tags），并按多维度筛选（优先级、标签、完成状态、截止日期、所属列表）。

**Blocked by:** 02 — 状态管理层

**Status:** ready-for-agent

- [ ] 搜索页：输入关键词 → 实时搜索（防抖 300ms）
- [ ] 搜索范围：title、detail、tags 字段
- [ ] 搜索结果按匹配度排序（标题匹配优先）
- [ ] 筛选面板：优先级（high/medium/low）
- [ ] 筛选面板：标签（多选，展示用户所有标签）
- [ ] 筛选面板：完成状态（已完成/未完成）

- [ ] 搜索 + 筛选支持组合使用
