# 08 — 分享/导出 + 许可协议

**What to build:** 用户可将 todo 列表导出为纯文本或 Markdown 格式（可复制/分享），应用包含许可协议和关于页面。

**Blocked by:** 02 — 状态管理层

**Status:** ready-for-agent

- [ ] 导出功能：选择列表 → 生成纯文本格式
- [ ] 导出功能：选择列表 → 生成 Markdown 格式
- [ ] 导出内容包含：标题、优先级、标签、截止日期、完成状态
- [ ] 导出文本可一键复制到剪贴板
- [ ] 许可协议页面：展示完整许可文本
- [ ] 关于页面：应用名称、版本、许可入口
- [ ] 设置页入口跳转到许可协议和关于页
