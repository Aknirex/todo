# 06 — 主题、本地化与 JSON 备份恢复

**What to build:** 用户可以在本地设置中切换简体中文/English 和浅色/深色主题，并通过 JSON 备份保护和恢复 Todo 数据。备份导入默认合并当前数据，冲突可见且整个导入过程具备原子性。

**Blocked by:** 03 — Todo 详情与移动端编辑生命周期

**Status:** ready-for-agent

- [ ] 用户可以切换简体中文和 English，选择在 App 重启后保持
- [ ] App 默认跟随系统浅色/深色主题，用户可以手动覆盖并持久化选择
- [ ] 主题和语言设置使用统一本地化与 Design System，不导致页面硬编码文案或视觉分叉
- [ ] 用户可以导出包含 Todo、List、主题和语言设置的 JSON 备份
- [ ] JSON 备份不包含 Undo/Redo 历史
- [ ] 用户可以将 JSON 备份合并导入当前数据，备份中的 ID 得到保留
- [ ] 同 ID 且内容不同的记录产生冲突报告，不静默覆盖当前数据
- [ ] 导入校验失败、冲突处理失败或持久化失败时整体回滚
- [ ] 成功导入后 Todo/List/设置可立即查看，Undo/Redo 栈为空
- [ ] 设置、导出、导入、冲突和回滚行为都有应用层、数据库和 Widget 测试
