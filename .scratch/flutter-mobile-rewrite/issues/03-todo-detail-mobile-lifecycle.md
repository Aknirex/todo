# 03 — Todo 详情与移动端编辑生命周期

**What to build:** 用户可以从首页进入 Todo 详情，编辑全部 Todo 字段，并在移动端新建和返回时获得确定的焦点、键盘和保存行为。新建与编辑都通过 Todo 工作区完成，用户不需要理解页面生命周期或数据库写入时机。

**Blocked by:** 02 — 默认 List 与 Todo 核心闭环

**Status:** done

- [x] 点击首页“+”后打开新建编辑页，并自动聚焦 detail 输入框
- [x] 新建页允许编辑标题、详情、Priority、DueDate 和 Tag
- [x] 只有点击“创建”按钮才提交新 Todo，页面内返回按钮放弃新建
- [x] 点击“创建”时即使标题和详情为空也能创建空白 Todo
- [x] 新建页第一次系统返回只收起键盘；键盘已收起后系统返回离开页面且不提交
- [x] 点击首页 Todo 行进入详情编辑页，并正确加载全部字段
- [x] 页面返回、Android 系统返回和返回手势离开详情页时保存变更
- [x] 一次详情编辑的多个字段变化只提交一次更新，未变更时不产生更新
- [x] Tag 去除首尾空白、丢弃空标签并在同一 Todo 内去重
- [x] DueDate 按设备本地日历日期保存和展示，不携带具体时刻
- [x] 新建焦点、键盘、返回、编辑保存和字段约束有 Widget/应用层测试
