# 07 — 移动端视觉与平台交互硬化

**What to build:** 将已完成的首页、详情、搜索、历史操作和设置体验统一收敛到移动端 Design System，并在 Android+iOS 真机上处理安全区、状态栏、键盘、焦点、滚动、返回手势和触控目标问题，使原型行为在真实设备上稳定呈现。

**Blocked by:** 04 — 删除与持久化 Undo/Redo; 05 — 本地搜索、筛选与排序; 06 — 主题、本地化与 JSON 备份恢复

**Status:** ready-for-agent

- [ ] 首页、详情、搜索、设置和 Undo/Redo 控件使用统一颜色、字号、间距、圆角和状态 token
- [ ] 关键按钮、图标按钮、完成控件、Tag、筛选入口和“+”按钮的触控目标至少为 48dp
- [ ] Android 和 iOS 的状态栏、安全区和底部手势区域不遮挡内容或控件
- [ ] 新建和详情输入在键盘弹出时保持可见，焦点转移和键盘收起行为稳定
- [ ] Android 系统返回与 iOS 返回手势不丢失详情编辑内容，也不误提交新建 Todo
- [ ] 长列表、搜索结果和筛选面板滚动时没有触控区域错位或内容裁切
- [ ] 中文、English 和混排文本在常见字体尺寸下不被裁切或溢出
- [ ] 浅色、深色主题和空状态在各主要页面保持视觉一致
- [ ] 关键页面和状态具备 Golden 回归测试，并在 Android 真机与 iOS 模拟器或真机上完成交互核验
