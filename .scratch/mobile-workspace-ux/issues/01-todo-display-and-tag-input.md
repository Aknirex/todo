# 01 — Todo 展示摘要与 Tag 输入规范化

**What to build:** 无标题 Todo 在工作区使用详情摘要作为可识别的展示文本，并让 Tag 输入同时支持半角和全角逗号。用户可以依靠列表内容识别 Todo，且 Tag 仍会自动去除空白、忽略空值并去重。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 有标题 Todo 的显示文本保持不变。
- [ ] 无标题但有详情的 Todo 使用详情开头约 40–60 个字符作为展示文本，超出部分显示省略号。
- [ ] 无标题且无详情的 Todo 保持可见，并使用稳定的空白展示处理。
- [ ] 无标题 Todo 的详情摘要同时用于标题升序和降序排序。
- [ ] Tag 输入支持半角逗号、全角逗号和混合分隔符。
- [ ] Tag 解析继续去除首尾空白、忽略空项并去重。
- [ ] 纯逻辑测试和工作区 widget 测试覆盖上述行为。
