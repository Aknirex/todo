# 03 — 移动端工作区搜索入口

**What to build:** 移动端工作区不再永久占用一整行搜索框，而是通过顶栏搜索图标进入紧凑的胶囊搜索界面。展开后用户仍可搜索标题、详情和 Tag，清除或提交查询，并能专注于搜索内容。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 移动端首屏以搜索图标替代常驻搜索输入框。
- [ ] 点击搜索图标后，搜索表面以快速动画展开为胶囊形输入区域。
- [ ] 展开状态中搜索图标位于左侧，清除或提交操作位于右侧。
- [ ] 搜索展开时工作区背景内容被视觉弱化，但不会丢失当前 Todo 和查询状态。
- [ ] 搜索继续覆盖标题、详情和 Tag，并保留现有 debounce、标题匹配优先和高亮行为。
- [ ] 清除或退出搜索后，工作区恢复原有内容和筛选状态。
- [ ] 搜索输入中的中英文文本在移动尺寸下完整显示，不发生纵向裁切。
- [ ] 工作区 widget 测试覆盖展开、输入、提交、清除和收起。
