# 02 — 工作区本地化与分段空状态

**What to build:** 工作区和 Todo 编辑流程使用完整、统一的中文与英文文案。移除主页面语言切换和冗余工作区文案，并让未完成、已完成分段的空状态明确表达各自状态。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 工作区不再显示多余的工作区副标题或冗余搜索提示。
- [ ] 主页面 overflow 菜单移除语言切换，语言切换仍可从 Settings 使用。
- [ ] Priority、Tag、DueDate、Undo、Redo 在中文和英文环境均显示本地化文案。
- [ ] 搜索、筛选、排序、Todo 表单、提示和 tooltip 均使用对应 locale 的文案。
- [ ] 未完成分段和已完成分段使用不同的空状态文案。
- [ ] 中英文切换后，工作区和编辑流程不显示未翻译的领域术语。
- [ ] 双 locale widget 测试覆盖菜单、空状态和用户可见标签。
