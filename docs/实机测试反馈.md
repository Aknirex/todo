## 问题

1. “todo工作区”文本多余，slogan“专注记录下一件要做的事”，搜索提示“搜索标题、详情或tag”多余
2. 搜索框占用了太多空间
3. 筛选下拉栏遮住了其展开按钮（priority等文本的按钮）
4. 排序不能单占一行，排序和筛选应该同级
5. 新建按钮太靠下，不在右手拇指热区
6. 新建todo输入完详情内容后，需要收起输入框才能看到“新建”按钮，再点击才能创建
7. 无标题而有详情的todo应该在主页面中显示详情内容的前若干字符，但是现在只能显示标题（空的）
8. 新建的todo（无论是否手动编辑了优先级，）不显示优先级标签，只有编辑设置了截止日期后才显示优先级和截止日期标签
9. “还没有 todo。”文本应该随未完成、已完成而显示不同的文本
10. 主页面下拉选单中switch to english应该删掉
11. 缺少本地化。只有英文：priority，tag，duedate，undo，redo
12. 所有下拉栏的动画较慢，应该再快些
13. 新建页面tag分割不支持全角逗号，不方便

## 建议

1. 移除多余文本。
2. 搜索框改为图标按钮，去掉搜索提示文本，放到顶栏下拉选单按钮左侧。点击后播放动画：搜索图标稍下移同时展开为胶囊体搜索框，最终搜索图标在左侧，“->”按钮在右侧；主页面其它内容变模糊作为背景。开发中管这个状态叫搜索页，可以展示小胶囊体标签样式的搜索记录
3. 筛选面板改为向下展开或弹出式（dropdown/bottom sheet），并保证展开后与触发按钮之间有足够间距，避免遮挡“Priority”等按钮。
4. 排序与筛选置于同一入口或同一行，作为同级操作，不让排序单独占用一行。
5. 将“新建”按钮移到屏幕右下角拇指热区（FloatingActionButton 位置），保证单手可点。
6. 为了让键盘弹出时保持“新建”按钮可见，输入详情后无需先收起键盘即可直接创建，重做新建页面：改为主页面为模糊背景，底部对齐铆钉输入框的若干组件，一些组件共用一行而不是独占，示意：
```json
{
    {标题输入框},
    {详情输入框}，
    {{优先级竖直限位转动轮盘（较窄）},{tag输入框（较宽）}},
    {{截止日期选择按钮或展示标签（很宽）},{创建按钮（很窄）}}
}
```
（新建todo页面不记录撤销重做功能，交给输入法；新建页无撤销、重做按钮。）
7. 无标题的 Todo 在列表中展示详情内容的前若干字符（建议 40–60 字）作为占位标题，超过则省略。（也作为字典排序的值）
8. 新建的 Todo 默认即显示 Priority 标签（含默认 medium），不等到设置 DueDate 才展示 Priority/DueDate 标签。tag同理。
9. 未完成与已完成两个分段的空状态文案分别显示，如“还没有未完成的 todo。”与“还没有已完成的 todo。”。
10. 删除主页面下拉选单中的 “Switch to English”，语言切换统一收敛到设置页。
11. 补齐本地化：将 Priority、Tag、DueDate、Undo、Redo 等所有用户可见术语纳入 l10n，中文与英文环境均使用本地化文案。
