# Agent Brief — 整体 UI 尺寸不适合现代手机体验

> *This was generated by AI during triage.*

**Category:** enhancement
**State:** ready-for-human
**Summary:** 全局 UI 偏小：触控目标、字号、间距按老旧小屏标准设计，在现代手机上显得局促

**Why this is ready-for-human:**
本条涉及明确的设计取舍，不适合完全委托代理执行：

- **目标视觉语言未定义** —— 是整体等比放大，还是重新编排层级（放大触控目标的同时收紧留白）？需要人拍板
- **设计令牌的具体取值** —— 字号梯度、触控目标尺寸、间距节奏的具体数值是设计决策
- **验收需要设备矩阵** —— 现代安卓机型差异大（屏占比、像素密度、挖孔），"适合现代手机"必须人工在真机上确认效果
- 决策确定后，实现部分（改设计令牌、落地到各页面样式）可再委派代理

**Current behavior:**
- 全局基准字号 28rpx（约 14px），正文偏小
- 触控目标远低于现代触控规范：`.icon-btn` 68rpx（约 34px）、`.pill`/`.todo-check` 40rpx（约 20px）、`.dropdown-trigger` 68×56rpx，而现代标准是 48dp（约 96rpx）以上
- 列表项、间距、图标整体偏小偏密，与现代手机（大屏、高密度）不匹配

**Desired behavior（供人类决策，决策后转 ready-for-agent 实施）：**
- 所有可交互元素（按钮、图标按钮、勾选框、标签、下拉触发、FAB）触控目标 ≥ 48dp（96rpx）
- 正文与标题字号提升到现代移动端可读梯度（建议正文 ≥ 16px/32rpx 量级）
- 间距、圆角、图标尺寸按同一比例体系升级，各页面一致
- 优先通过设计令牌（CSS 变量）驱动，避免逐页硬编码

**Key interfaces:**
- `src/App.vue` 全局设计令牌（`--bg`、`--text-*`、`--radius` 等 CSS 变量与全局组件类 `.topbar`、`.icon-btn`、`.todo`、`.pill`、`.fab`）
- 各页面样式中的 rpx 取值（index、detail、search、agent、settings 等页面）
- 与 brief-01（状态栏让位）协同：本次尺寸调整不应破坏已修复的状态栏适配

**Acceptance criteria（实施阶段适用）：**
- [ ] 所有可交互元素触控目标 ≥ 96rpx（48dp）
- [ ] 正文可读性提升，中英文混排无裁切
- [ ] 在至少一台主流安卓机型与 H5 上视觉一致、无布局错位
- [ ] 状态栏适配（brief-01）与新建聚焦（brief-02）等已修复行为无回归

**Out of scope:**
- 品牌重塑、图标重绘、字体族更换
- 深色模式主题调整（仅跟随既有令牌）
- 平板/大屏布局适配
