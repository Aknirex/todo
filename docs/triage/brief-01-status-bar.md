# Agent Brief — 状态栏遮挡顶部内容

> *This was generated by AI during triage.*

**Category:** bug
**State:** ready-for-agent
**Summary:** 安卓 app 中页面顶部（topbar、侧栏头部、新建/搜索浮层头部）被系统状态栏遮盖

**Current behavior:**
应用使用自定义导航（全局 `navigationStyle: "custom"`），页面从屏幕顶部 edge-to-edge 渲染。顶部栏是固定 `height: 88rpx` 的普通元素，没有为系统状态栏预留高度。在安卓真机（app-plus 运行环境）上，状态栏区域与页面内容重叠：topbar 内容、侧栏头部、新建任务浮层与搜索浮层顶部的图标/标题都被状态栏遮挡，且状态栏背景不透明时内容不可见。全代码库目前没有任何状态栏高度处理（未使用 `uni.getSystemInfoSync().statusBarHeight`，也未使用 `var(--status-bar-height)`）。

**Desired behavior:**
在 app-plus（安卓）上，所有自顶向下的内容容器都必须把系统状态栏高度计入顶部内边距，保证：

- 主页 topbar（菜单按钮、标题、撤销按钮）完整显示在状态栏之下
- 侧栏 `.sidebar-header`（折叠按钮、应用名）不被遮挡
- 新建任务浮层 `.new-task-top` 顶部栏不被遮挡
- 搜索浮层 `.search-overlay-inner` 顶部栏不被遮挡
- 状态栏区域背景与下方容器背景一致（卡片色），无突兀色块

**Key interfaces:**
- 全局 `.topbar` 样式（所有页面共用）— 需要为状态栏让位，推荐使用 uni-app 在 app-plus 环境提供的 CSS 变量 `var(--status-bar-height)`（在 `<style>` 非 scoped 处或通过条件编译使用），或运行时读取 `uni.getSystemInfoSync().statusBarHeight`（单位 px）
- 侧栏头部、新建任务浮层、搜索浮层 —— 与 topbar 相同的让位处理；这些容器当前 `top: 0` 或固定高度，需与状态栏高度联动
- 注意仅对 app-plus（安卓）生效，H5 与小程序行为保持不变

**Acceptance criteria:**
- [ ] 安卓真机（至少一台常见机型，如带刘海/挖孔屏）上，主页 topbar 全部内容完整显示在状态栏下方，无重叠
- [ ] 打开侧栏、新建浮层、搜索浮层，各自的顶部栏内容均不被状态栏遮挡
- [ ] 状态栏与下方容器背景连续一致，无裁切或错位
- [ ] H5 与微信小程序端外观与修复前一致（无回归）
- [ ] 旋转或不同状态栏高度机型下不出现硬编码偏移（不得写死固定 px 值）

**Out of scope:**
- 底部手势条/导航条安全区（home indicator）适配 —— 另立问题
- iOS 灵动岛等平台特例（如存在，按同一机制处理，但验收以安卓为准）
- 状态栏图标颜色/样式调整（`navigationBarTextStyle` 语义之外的定制）

**备注：** 修复后需真机复测全部页面（含浮层），因为状态栏让位可能暴露浮层定位、下拉面板位移等关联问题。
